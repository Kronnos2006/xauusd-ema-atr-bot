# Kronnos — prueba positiva RFC3161 sin IA
Se añade una prueba end-to-end que crea autoridad de prueba efímera, emite un token RFC3161, verifica el token usando openssl ts -verify y exige rechazo ante manipulación del contenido.

**No equivale a certificado de una TSA independiente:** la CA se fabrica en el mismo job de CI. Esto comprueba interoperabilidad y cadena criptográfica, pero no acredita custodia externa ni evita falsificaciones de un operador que controle la CA.

La custodia real requiere una raíz TSA fijada por un custodio independiente, recibos externos y almacenamiento con política WORM inmutable. El N exhaustivo y DSR de #42 permanecen por verificar. El script corre bajo GitHub Actions en cada cambio y usa cero tokens de IA.
