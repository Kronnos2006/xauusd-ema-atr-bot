# ORION — Política de autoría operativa ChatGPT
Fecha: 2026-10-23 (America/Costa_Rica).

## Norma
Todo cambio realizado directamente por ChatGPT debe documentar su autoría operativa sin suplantar al titular de GitHub.
Para commits futuros usar un mensaje descriptivo y estas líneas:
Operated-By: ChatGPT (OpenAI)
Requested-By: usuario / referencia de autorización
Review-Status: pending / independently-reviewed
Validation: enlace a pruebas o 'no ejecutadas'

Para PR, issues y cambios documentales registrar: fecha, objetivo, archivos, motivación, impacto, riesgos, pruebas, ejecutor ChatGPT, revisor real (o pendiente), autorización y evidencia.
El autor técnico del commit seguirá siendo la cuenta autenticada en GitHub; Operated-By identifica quién produjo operativamente el cambio, no modifica la identidad Git.
No reescribir commits antiguos ni atribuir a ChatGPT trabajo de Claude, agentes o GitHub Actions sin evidencia.
Los cambios importantes requieren revisión y validación independiente antes de integrarse. Nunca declarar realizadas pruebas o aprobaciones inexistentes.

## Aplicación inicial
Ejecutado por: ChatGPT (OpenAI). Solicitado por: usuario, 2026-10-23.
Objeto: crear esta política documental; ningún cambio a workflows, trading o procesos automáticos.
Validación: escritura GitHub; pruebas de software no aplican. Revisión independiente pendiente.
